# XIRASM 0.2.20

本版本为 Meta 语言加入原生 crypto 助手，并交付 Android NativeActivity
链路的 APK 打包 include。

- `crypto.crc32` 与 `crypto.adler32` 以整数返回 IEEE CRC-32 和 Adler-32
  校验值；`crypto.sha1` 与 `crypto.sha256` 以 `bytes` 返回 20 字节与
  32 字节摘要。
- 每个助手都接受 `bytes` 值或 `string`，并且是纯表达式，因此在 defer
  终局块内同样可求值。
- 哈希以原生速度执行。兆字节级载荷立即完成，不再把编译时间花在
  逐字节解释扫描上。
- `include/format/zip.inc` 生成 STORED ZIP 档案：zipalign 兼容对齐、
  急切中央目录构造与成品镜像完整性自检。`include/format/apk.inc`
  在其上封装 NativeActivity 打包：二进制 AndroidManifest.xml、112 字节
  classes.dex 引导和 16 KiB 对齐的原生库。`document/apk.md` 记录了从
  ELF 共享库到模拟器签名安装的完整链路。
- 语言参考第 15 章以英文和中文文档化 crypto 助手。

```asm
const payload: bytes = b"123456789"
const crc: u64 = crypto.crc32(payload)
const digest: bytes = crypto.sha256(b"abc")

assert(crc == 0xcbf43926);
assert(len(digest) == 32);
```

校验助手经单元测试、可汇编 fixture 与 API 矩阵对照标准测试向量验收；
`zip.inc` 回归产物在解释、查表与原生三种实现间逐字节一致。

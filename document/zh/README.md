# XIRASM 中文文档

XIRASM 是一款同时支持 x86、AArch64、RISC-V 与 SPIR-V 的现代汇编器：直接写汇编，直接生成 Windows、Linux、macOS 与 Android 上的可用产物。除了直接编写处理器指令，它还提供完整的编译期语言，用于计算、控制流、代码与数据生成、模块复用和小型 DSL。

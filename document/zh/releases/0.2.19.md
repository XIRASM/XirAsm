# XIRASM 0.2.19

本版本通过 `arm/a64.inc` 和 `arm/a64-macros.inc` 提供生成式 A64 指令编码器
与自然语法宏。两种接口共用一套经过验证的实现，覆盖 1743 条来源指令/别名
记录和 4358 个操作数形式。

- 整数算术、分支、延后地址引用和按页计算的 ADRP。
- 浮点、Advanced SIMD、lane、转换及结构访存。
- AES/SHA/CRC、LSE 原子操作、FP16、点积、BF16/I8MM 等扩展。
- 指针认证、BTI、MTE、屏障和系统操作，支持 663 个固定系统寄存器名。
- 直接 API 与自然宏共用寄存器角色、范围、对齐、寄存器配对和写回检查。

```asm
import("arm/a64-macros.inc")
mov x0, #42
add x1, x0, #1
fadd v0.4s, v1.4s, v2.4s
b.eq done
done:
ret
```

延后收尾现在能够在保留调用者绑定的情况下求值捕获操作数，包括局部 list
和 map 值。前向标签与地址表达式在布局后解析，不重新执行 Meta 程序。

生成函数和宏位于 `arm/a64/generated/instructions.inc` 与
`instructions-macros.inc`。原手写入口 `arm/arm64.inc` 和
`arm/arm64-macros.inc` 已退休；应迁移至新入口，直接调用改用 `a64_*`
操作数描述符 API。

生成结果可从固定版本的来源资料复现。Clang 字节对照、操作数拒绝矩阵及
独立边界测试覆盖两种接口。能够编码不代表所有设备支持相应扩展或允许执行
特权指令。尚不包含 SVE/SME、A32/T32 和已发布清单以外的可选指令族。
实际设备运行和汇编吞吐与编码正确性分别验收。

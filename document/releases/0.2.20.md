# XIRASM 0.2.20

This release adds native crypto helpers to the Meta language and ships the
APK packaging includes for the Android NativeActivity chain.

- `crypto.crc32` and `crypto.adler32` return IEEE CRC-32 and Adler-32
  checksums as integers. `crypto.sha1` and `crypto.sha256` return the
  20-byte and 32-byte digests as `bytes`.
- Every helper accepts a `bytes` value or a `string` and is a pure
  expression, so it also evaluates inside deferred finalizers.
- Hashing runs at native speed. A megabyte payload hashes immediately
  instead of spending compile time in an interpreted per-byte scan.
- `include/format/zip.inc` emits STORED ZIP archives with zipalign-compatible
  alignment, eager central-directory construction and a final-image
  integrity verifier. `include/format/apk.inc` layers NativeActivity
  packaging on top: a binary AndroidManifest.xml, the 112-byte classes.dex
  bootstrap and 16 KiB aligned native libraries. `document/apk.md`
  documents the full chain from ELF shared objects to signed emulator
  installs.
- Language reference chapter 15 documents the crypto helpers in English
  and Chinese.

```asm
const payload: bytes = b"123456789"
const crc: u64 = crypto.crc32(payload)
const digest: bytes = crypto.sha256(b"abc")

assert(crc == 0xcbf43926);
assert(len(digest) == 32);
```

Checksum helpers are validated against the canonical test vectors through
unit tests, an assembling fixture and the API matrix. `zip.inc` regression
output stays byte-identical across the interpreted, table-driven and native
implementations.

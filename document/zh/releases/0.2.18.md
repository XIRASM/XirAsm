# XIRASM 0.2.18

本版本在 Zig 前端新增指令形式的宏。宏体在源码 lowering 到达调用处时执行；
编码、布局和松弛阶段不会重跑 Meta 程序。

```asm
import("arm/arm64-macros.inc")
const VALUE: u64 = 42
movz x0, #VALUE
add x1, x0, #(VALUE + 1)
b.eq done
done:
ret
```

- 顶层 `macro` 声明支持精确参数数目重载、末尾可变参数、嵌套调用，以及现有
  Meta 变量和控制流。
- 不可变 `operand` 保留调用者的值绑定。`operand.text`、`operand.eval`、
  `operand.slice`、`operand.split` 提供拼写、表达式求值和有边界检查的操作数处理。
- 原生指令转发保留参数捕获信息，不再次扫描插入的文本。`isa(text)` 可显式绕过宏分派。
- 错误保留宏调用处和定义处的位置，包括原生编码及延迟收尾阶段报告的错误。
- 修正延迟块冻结时，局部声明被同名外层绑定错误替换的问题。
- 调用深度、展开次数、操作数嵌套和捕获依赖都有明确限制；分配失败会传播并清理所有权。

可选 A64 入口包装现有整数、分支和访存/地址指令族，不代表全部 A64 指令或浮点/SIMD
API 均有宏。宏名称不会自动按 ISA 隔离。静态标号仍属于模块，私有标号用 `sym.unique`
配合 `label.define`。捕获会复制可见值绑定，不再需要源码语法时宜保存求值结果。
原有 API-only 入口 `arm/arm64.inc` 继续可用。

完整规则见[语言指南](../language/05-functions-and-scope.md)和
[API 参考](../api-reference/02-functions-and-control-flow.md)。
`zig build test-macros` 可运行前端测试与 A64 宏样例。

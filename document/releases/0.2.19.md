# XIRASM 0.2.19

This release delivers generated A64 instruction encoders and natural statement
macros through `arm/a64.inc` and `arm/a64-macros.inc`. Both interfaces share one
validated implementation, covering 1743 source instruction/alias records and
4358 operand forms.

- Integer arithmetic, branches, deferred address references and page-relative ADRP.
- Floating-point and Advanced SIMD operations, lanes, conversions and structure loads/stores.
- AES/SHA/CRC, LSE atomics, FP16, dot products, BF16/I8MM and related extensions.
- Pointer authentication, BTI, MTE, barriers and system operations, with 663 fixed system-register names.
- Register-role, range, alignment, register-pair and writeback checks shared by direct APIs and macros.

```asm
import("arm/a64-macros.inc")
mov x0, #42
add x1, x0, #1
fadd v0.4s, v1.4s, v2.4s
b.eq done
done:
ret
```

Deferred finalization now evaluates captured operands while retaining caller
bindings, including local list and map values. Forward labels and address
expressions resolve after layout without rerunning the Meta program.

Generated functions and macros live in `arm/a64/generated/instructions.inc`
and `instructions-macros.inc`. The former hand-written `arm/arm64.inc` and
`arm/arm64-macros.inc` entries have been retired; migrate imports to the new
entries and direct calls to `a64_*` descriptor APIs.

Generation is reproducible from pinned source data. Byte comparisons against
Clang, operand rejection matrices and independent boundary tests validate both
interfaces. Encoding support does not imply that every device supports an
extension or permits privileged execution. SVE/SME, A32/T32 and optional families
outside the published manifests are not included. Device execution and assembly
throughput are separate from encoding correctness.
